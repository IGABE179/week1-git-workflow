# Week 1 Git Workflow – Banana Pancakes Recipe

A one-page static recipe site (HTML and CSS) built to practise a professional Git and GitHub workflow.

## How to open
Clone the repository and open `index.html` in a browser.

## Workflow used
- Planned the work as 5 GitHub Issues tracked on a GitHub Project board (Todo → In Progress → Done).
- Made every change on its own feature branch; nothing was pushed directly to `main`.
- Opened a Pull Request for each branch with `Closes #N` so the issue closed automatically on merge.
- Created an intentional merge conflict between `feature-header-a` and `feature-header-b` on the page title and resolved it locally with `git merge main`.
